Warrior talent icons use the names in `visualizer/data/talents_warrior.json`.
Classic icons were imported from the local Forever reference's cached
`assets/img/wowhead/icons/large/<name>.jpg` and converted to PNG. The four custom
talent icons came from `assets/img/talents/warrior/` in that reference, under its
included MIT license (see `data/warrior_sources/LICENSE`).

The cached game icons originate from
`https://wow.zamimg.com/images/wow/icons/large/<name>.jpg`.
Game artwork belongs to Blizzard Entertainment, consistent with the existing
class and spell assets. No runtime network connection is required.
