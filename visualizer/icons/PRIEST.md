Priest talent icons use the icon names in `visualizer/data/talents_priest.json`,
matching the Forever priest talent calculator:
https://www.wowhead.com/forever/talent-calc/priest

The missing assets were downloaded from Wowhead/ZAM using
`https://wow.zamimg.com/images/wow/icons/large/<icon-name>.jpg`
and converted to PNG for the visualizer's existing icon loader.

Artwork belongs to Blizzard Entertainment, consistent with the existing WoW
class and spell assets. These local images require no network access at runtime.
